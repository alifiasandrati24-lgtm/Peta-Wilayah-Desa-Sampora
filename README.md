# Peta Wilayah Desa Sampora

## Deskripsi
Repositori ini berisi data spasial dan hasil pemetaan wilayah Desa Sampora, Kecamatan Cikidang, Kabupaten Sukabumi, Jawa Barat.

Pemetaan ini disusun sebagai media informasi spasial untuk memberikan gambaran mengenai batas administrasi, wilayah RT, dan persebaran fasilitas umum di Desa Sampora.

## Isi Repositori
- `Desa_Sampora`: data batas administrasi desa.
- `RT SAMPORA`: data wilayah RT.
- `FASUM_SAMPORA`: data lokasi fasilitas umum.
- Peta hasil akhir: peta digital Desa Sampora dalam format PDF dan PNG.

## Perangkat Lunak
QGIS versi 3.44.14.

## Cara Membuka Data
1. Unduh file shapefile dari repositori ini.
2. Ekstrak file jika masih dalam bentuk ZIP.
3. Buka QGIS.
4. Pilih Layer → Add Layer → Add Vector Layer.
5. Masukkan file `.shp` yang ingin ditampilkan.

## Keterangan
Data disediakan untuk keperluan informasi spasial dan akademik. Penggunaan lebih lanjut perlu memperhatikan sumber data dan ketentuan penggunaannya.
